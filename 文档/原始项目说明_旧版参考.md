# 多人在线意图识别与推荐聊天系统

## 系统介绍

本系统是一套能精确识别用户意图和要求，并实现推荐的多人在线聊天系统。

设想一下，你和朋友们多日未见面，商议一起外出就餐。你从聊天界面切换到美食推荐软件开始查询餐厅。但是在你与朋友的沟通中，出现了某时段没空、不喜欢该口味、距离太远等因素，你不得不频繁往返于聊天界面和推荐平台进行不断地调整，这大幅降低了决策和行动效率。

针对这一缺失，本研究打算做两件事：第一，给聊天系统一套能精准捕捉日常社交场景中用户动态意图的模型，即意图识别模型；第二，利用第三方服务商配套服务，通过调用外部接口实现用户需求的查询和推荐。我们希望推动系统之间实现跨越，让机器成为用户社交沟通中高效的行动辅助伙伴，打通从聊天决策到服务落地的全流程。

**例如：**

- **聊天内容：**
  - 用户A：“晚上一起吃点啥？”
  - 用户B：“随便，辣的就行，离咱俩都近点的”

从对话可看出，用户A和用户B有外出就餐的需求，需求是辣味、门店距离适中。一般来说，用户得到这些需求后，就需要切换到地图软件进行筛选餐馆。但如果在检索过程中新增用户需求：

- 用户C：“我不想去吃辣，我想吃些清淡的饭菜，要不去吃寿司吧”

看完消息后你又得重新打开地图工具再次查询，操作重复、流程繁琐。
**所以我们的目标是**，做一个在线聊天系统，实现从识别用户意图和要求到最终推荐的全流程闭环。

## 快速上手使用

### 环境依赖安装

1. **运行环境**
- CPU：AMD Ryzen 7 5800Hwith Radeon Graphics
- GPU：vGPU-32GB(使用的是云服务器)
- 操作系统：Windows
- 使用的软件:conda和pycharm
- Python版本为3.10
    - 经过测试，在使用Python3.9时有概率出现部分python库调用报错的情况，建议使用3.10及以上的版本

2. **安装依赖**
- 在命令行中依次运行下列代码安装python库
    ```bash
    pip install modelscope
    pip install flask
    pip install flask_socketio
    pip install dashscope
    pip install --upgrade "volcengine-python-sdk[ark]"
    pip install transformers
    pip install matplotlib
    pip install datasets 
    pip install peft 
    pip install seaborn
    pip install scikit-learn
   ```

- 一般来说，python库下载速度会很慢，建议使用清华源下载
    ```bash
    -i https://pypi.tuna.tsinghua.edu.cn/simple
    ```
    使用示例：
    ```bash
    pip install flask -i https://pypi.tuna.tsinghua.edu.cn/simple
    ```

### 快速上手

1. **安装模型**
   - 运行 `download.py`
   将会下载模型到`Qwen3-4B`文件夹中

2. **训练模型**
    - 运行 `train.py`
   将使用`data`文件夹中的数据集对Qwen3-4B模型进行训练，训练后的LoRa权重和图片会保存在`model_output/lora_qwen_4b_intent`和`model_output/train_results`

3. **测试模型**
    - 运行 `test.py`
   将对训练好的模型进行测试，结果保存到`model_output/test_results`文件

4. **配置外部插件API**
    - 编辑`tools/config.py`文件，完成以下第三方服务的参数配置：
      - 豆包（Doubao）大模型
      - 通义千问（Qwen）大模型
      - Coze插件平台
    教学视频参考

5. **意图识别系统的使用**
    - 运行 `app.py`
        - 运行 `app.py` 将会给出在线聊天系统链接
        ![alt text](image1.png)
        - 可进行注册与登录
        ![alt text](image2.png)
        - 登录完毕后即可进入聊天界面进行聊天
        ![alt text](image3.png)

### 系统文件讲解

1. **数据集**
    - 位于`data`文件夹中
        共包含3类意图：约饭，出行，无意图

2. **意图识别训练、测试与使用**
    - Qwen模型训练：`train.py`
    - Qwen模型测试：`test.py`
    - Qwen模型加载与使用：`model_loader.py`

3. **预处理模型**
    - 调用大模型对音频，图片和视频文件进行预处理，配置文件位于`tools/config.py`
      -  预处理音频文件： `tools/pre_audio.py`
      -  预处理图片文件： `tools/pre_image.py`
      -  预处理视频文件： `tools/pre_video.py`

4. **外部插件调**
    - 调用大模型对音频，图片和视频文件进行预处理，配置文件位于`tools/config.py`
        - 查询高铁信息文件：`tools/travel.py`
         - 查询饭店文件：`tools/dining.py`

5. **在线聊天系统**
    - 网页代码：`templates`
    - 用户聊天记录：`data_user/chat_history.json`
    - 用户注册信息：`data_user/users.json`
    - 用户聊天发送的多模态文件：`static/uploads`
    - 在线聊天系统服务器文件：`app.py`  
        - 在线聊天系统服务器文件负责在线聊天系统的可视化与实时通信
        - 当前配置仅支持本地访问,如要实现外部网络访问网页,可以通过内网穿透实现(自行查询教程)
    - 系统机器人文件：`bot.py`
        - 系统机器人文件负责对调用各个模块的文件，对接收到的用户发送的信息进行处理，并返回内容
